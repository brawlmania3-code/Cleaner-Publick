# Cleaner 2.0 — Public Edition

Утилита для безопасной очистки файлов с перемещением в корзину (не удаление навсегда).

## ⚠️ Важное предупреждение

- Скрипт перемещает файлы в собственную корзину: `%TEMP%\CleanerTrash`.
- **Всегда тестируйте сначала на тестовых файлах.**
- Антивирусы могут помечать скрипт как подозрительный — это ложное срабатывание, так как используются легитимные команды PowerShell.
- Не используйте на рабочих компьютерах без согласования с ИТ-отделом.
- Файл `cleaner_code.txt` содержит ваш личный код доступа и **не должен** загружаться в репозиторий (он игнорируется благодаря `.gitignore`).

## Как установить и запустить

1. Скачайте архив с релизом или клонируйте репозиторий.
2. Распакуйте в любую папку.
3. Запустите `cleaner.bat`.
4. При первом запуске придумайте код доступа (он сохранится локально в `cleaner_code.txt`).
5. Пользуйтесь меню.

## Возможности

- Очистка Temp с перемещением в корзину.
- Поиск старых и больших файлов.
- Поиск дубликатов по хешу.
- Отчёт по типам файлов.
- Мониторинг CPU/RAM и места на дисках.
- Корзина с возможностью восстановления.
